# Flujos de usuario (MVP)

## 1. Cliente contrata trabajador
1. Cliente se registra e inicia sesión.
2. Cliente completa perfil básico.
3. Cliente busca trabajadores por ciudad (Mar del Plata), tarifa y disponibilidad.
4. Cliente selecciona perfil con reviews.
5. Cliente envía solicitud (fecha, horas, notas).
6. Trabajador acepta/rechaza.
7. Si acepta, queda confirmado y visible en historial.
8. Al finalizar, cliente deja review.

## 2. Trabajador recibe trabajo
1. Trabajador crea perfil con experiencia, habilidades y tarifa.
2. Carga disponibilidad semanal.
3. Sube datos para validación de identidad.
4. Recibe solicitud.
5. Acepta/rechaza.
6. Completa servicio y actualiza estado.

## 3. Administrador modera plataforma
1. Admin revisa usuarios nuevos.
2. Aprueba/rechaza verificaciones de identidad.
3. Gestiona incidencias/denuncias.
4. Revisa métricas: activación, match rate, repetición de clientes.
